# 参考：权限、状态和规则

> **适合谁：** 分店经理和技术支持。界面操作步骤见[教程](../01-manual-usuario/)。

选择员工角色时会加载这些权限。之后可以在*收银员权限*里手动调整；如果改了角色，会恢复为新角色的权限。

| 登记销售 | | | ✓ | ✓ |
| 登记支出 | | | ✓ | ✓ |
| 付款给供应商或结清账款 | | | | ✓ |
| 取现 | | | ✓ | ✓ |
| 收回客户欠款 | | | ✓ | ✓ |

| 新建或编辑客户 | | | ✓ | ✓ |
| 新建或编辑供应商 | | | | ✓ |
| 新建销售类别 | | | | ✓ |
| 开班或交班 | | | ✓ | ✓ |
| 录入订单 | ✓ | ✓ | | ✓ |
| 作废别人的订单 | | ✓ | | ✓ |

来源：`core/roles.py`。

## 状态

| 对象 | 状态 | 何时变化 |
|---|---|---|
| **订单** | 未结 → 已收款 · 未结 → 已作废 | 在收银台收款时 · 在柜台作废时 |
| **收银班次** | 开班 → 交班 | 确认交班时。交班后不能修改 |
| **发货单** | 已发出 → 已收货 | 分店确认收货时 |
| **半边胴体** | 在冷库 → 已分割 | 确认分割时 |
| **盘点** | 进行中 → 已关闭 · 进行中 → 已作废 | 关闭时（调整库存）· 作废时（不动库存） |

## 需要了解的规则

| 模块 | 规则 |
|---|---|
| 订单 | 每家分店每天编号。只能收款一次。收款时扣库存 |
| 订单 | 助理只能作废自己的；正式屠宰工和经理可以作废任何人的 |
| 收银台 | 没开班不能操作。如果有前一天没交班的班次，要先交班 |
| 收银台 | 交班差额必须写原因，记入 *Diferencias de Caja*（收银差额）账户 |
| 收银台 | 选了客户才出现 Fiado（赊账）。赊账不增加现金 |
| 支付方式 | 没有分配时收银员看到全部方式；有分配时只看到启用的 |
| 收货 | 收半边胴体时默认第一个启用的“冷藏库”类型冷库 |
| 冷库 | 挂了 4 天及以上显示橙色 |
| 盘点 | 同一时间只能有一个盘点。只负责清点的人看不到应有数量 |
| 每周结算 | 关闭后库存等于盘点数并保存平衡。不能撤销 |
| 商品目录 | 商品、价格、模板和发货单在总部录入 |
| 语言 | 小票、PDF 和 Excel 永远是西班牙语 |
