# 常见问题

> **适合谁：** 所有人。每一行说明**遇到什么**、**为什么**和**怎么办**。

> 首先记住：**收银错误不要靠修改班次来解决。** 要用留痕的方式更正（账户调整）。

## 登录和工位
| 遇到…… | 原因…… | 怎么办 |
|---|---|---|
| “用户名或密码错误” | 密码输错或账号已停用 | 检查大小写；还不行，请经理检查账号 |
| 找不到我的工位 | 没给你开通 | 请经理加上（[18](../01-manual-usuario/18-alta-de-personal.md)） |
| 平板打不开页面 | 没连店里的 Wi-Fi 或电脑没开 | 连 Wi-Fi，开电脑 |
| 界面全是西班牙语（或中文） | 语言保存在你的账号里 | 点 **中文** 或 **ES**（[02](../01-manual-usuario/02-cambiar-idioma.md)） |

## 柜台
| 遇到…… | 原因…… | 怎么办 |
|---|---|---|
| “与分店电脑失去连接” | Wi-Fi 断了 | 等一下再点**发送到收银台**：不会重复 |
| 找不到某个部位或价格不对 | 由加工厂录入 | 告诉经理 |
| 不能作废订单 | 是别人的，或已收款 | 正式屠宰工或经理可以作废别人的 |

## 收银台
| 遇到…… | 原因…… | 怎么办 |
|---|---|---|
| “有一个前一天的班次没有关闭” | 昨天没交班 | **关闭上一个班次**，再开班 |
| 找不到订单 | 没发送、已收款或已作废 | 问屠宰工 |
| 提示订单已收款 | 另一个收银台先收了 | 继续下一张 |
| 没有 **Fiado**（赊账） | 没选客户 | 先选客户 |
| 不能确认交班 | 有差额但没写原因 | 写上原因 |
| 交班时填错了 | 班次已关闭 | 经理做账户调整（[22](../01-manual-usuario/22-controles-de-la-semana.md)） |

## 收货和库存
| 遇到…… | 原因…… | 怎么办 |
|---|---|---|
| 看不到发货单 | 没同步或已收货 | 等一分钟；还没有就告诉经理 |
| 不能分割 | 你是助理 | 由正式屠宰工或经理分割 |
| 某商品是负库存 | 分割没录入、用别的名字卖了，或到货没录入 | 做一次[抽查盘点](../01-manual-usuario/17-conteo-de-control.md) |

## 盘点和每周结算
| 遇到…… | 原因…… | 怎么办 |
|---|---|---|
| “已有一个进行中的盘点” | 还有一个没做完 | 做完它，或请正式屠宰工作废 |
| 某行有 **!** | 丢弃的货缺原因 | 选原因 |
| 不能关闭结算 | 缺必须盘点的商品 | 去数（没有就录 0） |
| 损耗是红色 | 超过 6% | 检查金额最大的短少 |

## 同步和总部
| 遇到…… | 原因…… | 怎么办 |
|---|---|---|
| 总部看到分店是红色 | 电脑关了或断网 | 开电脑或检查网络；分店照常营业 |
| 在分店改的价格又变回去了 | 价格由总部录入 | 在总部改（[26](../01-manual-usuario/26-catalogo-precios-y-plantillas.md)） |
| 找不到改结算日的地方 | 这个版本后台没有 | 找技术支持 |
