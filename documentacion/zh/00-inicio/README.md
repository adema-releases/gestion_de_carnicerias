# 从这里开始：系统是什么，谁负责什么

> **适合谁：** 第一次使用系统的人。  **时间：** 10 分钟。

Gestión de Carnicerías（肉店管理系统）是**一家肉类加工厂和它自己的连锁肉店**使用的系统。每家肉店在这里称重卖肉、收款、收货，并检查还剩多少货。加工厂在办公室就能看到每家分店的经营情况。

## 业务模式

```
            加工厂（总部）
   采购活畜、屠宰，然后给分店发货
                    │
   半边胴体、鸡肉、香肠…… ──► "卖"给每家分店（记在往来账上）
                    │
     ┌──────────────┼──────────────┐
  Centro 分店      Norte 分店      Sur 分店         ← 每家都是开在超市里的肉店
     │
     ├─ 收货：接收、挂好并分割牛肉
     ├─ 柜台：称重并录入订单
     ├─ 收银台：向顾客收取订单的款项
     └─ 每周二：每周结算（盘点剩下的货）
```

- **加工厂**给分店发货（主要是**半边胴体**），这笔钱记为分店的欠款。分店用**汇款**慢慢还。
- **分店**把每个半边胴体**分割**成各个部位，按公斤卖出并收款。
- 最重要的是管好**钱**（收银台交班要对得上）和**公斤数**（从进货到卖出，肉不能不明不白地少了）。所以每周要把所有货盘点一次：这就是**每周结算**。

> **没有网络也能卖货。** 每家肉店都有一台装好系统的电脑。电脑每分钟自动和加工厂同步；断网时肉店照常营业，网络恢复后会自动上传所有数据。

## 肉店的工位

每台**设备**（电脑、平板或手机）都设置为一个**工位**。工位决定打开哪个界面。

| 工位 | 在哪里 | 做什么 | 谁用 |
|---|---|---|---|
| **柜台** | 柜台上的平板或手机 | 给部位称重，录入**订单**并发送到收银台。**这里不收钱** | 助理屠宰工和正式屠宰工 |
| **收银台** | 收银电脑 | 开班和交班，**收取**订单款项，按件销售、赊账、支出和取现 | 收银员 |
| **收货** | 冷库旁边的电脑或平板 | **收货**，挂好并**分割**半边胴体，查看**库存**，**盘点** | 正式屠宰工、助理屠宰工和经理 |
| **后台（Admin）** | 任何电脑的浏览器 | 员工、工位、支付方式、报表 | 分店经理 |
| **总部面板** | 加工厂办公室 | 查看所有分店，发货，往来账，商品目录和价格 | 加工厂 |

## 谁能做什么

| 角色 | 可以 | 不可以 |
|---|---|---|
| **助理屠宰工** | 录入和作废自己的订单，收货，查看库存，盘点 | 收款，分割，关闭盘点 |
| **正式屠宰工** | 助理的所有权限，加上分割、作废别人的订单、关闭盘点和每周结算 | 收款 |
| **收银员** | 开班和交班，收款，支出，取现，赊账和收回欠款 | 收货、库存和盘点 |
| **分店经理** | 以上全部，再加上后台和财务看板 | — |
| **加工厂** | 商品目录、价格、发货单和各分店的往来账 | 修改分店的销售或盘点 |

给员工选择**角色**后，系统会自动加载这些权限。见[新增员工](../01-manual-usuario/18-alta-de-personal.md)。

## 一笔销售是怎么走的

1. 屠宰工在柜台给 1.350 公斤的 Vacío（腹肉）**称重**，加到**订单**里。
2. 点**发送到收银台**：系统给出一个**号码**（例如 #19），告诉顾客。
3. 顾客到收银台说“19 号”。收银员点一下就**调出**这张订单，收款，给小票。
4. 这些公斤数从该部位的**库存中扣除**。
5. 周二**每周结算**时，比较应剩的和实际剩的。
6. 这一切都**上传到加工厂**，在总部面板上可以看到。

## 词汇表

| 词 | 意思 |
|---|---|
| **加工厂 / 总部** | 公司本身。负责发货并管理所有分店 |
| **分店** | 每一家肉店，开在超市里的店面 |
| **工位** | 一台设备的用途：收银台、柜台或收货 |
| **订单（comanda）** | 屠宰工在柜台录入的、已称重的部位清单。在收银台收款 |
| **销售（venta）** | 在收银台已经收完款的订单（或其他商品） |
| **半边胴体（media res）** | 屠宰后的半边牛，加工厂就是这样送来的。挂在冷库里 |
| **胴体编号（garrón）** | 每个半边胴体的识别码 |
| **分割（desposte）** | 把半边胴体切成各个部位（Asado 肋排、Vacío 腹肉、Nalga 后腿……） |
| **分割模板** | 每个部位占半边胴体的百分比。例如 Asado de tira（肋排）15% |
| **损耗（merma）** | 损失的公斤数：卖不掉的骨头和肥油、丢弃的货、盘点时少的货 |
| **冷库（cámara）** | 冷藏库、展示柜或冷冻柜 |
| **送货单（remito）** | 记录到货内容的单据。加工厂的叫**发货单（despacho）** |
| **库存（stock）** | 系统认为**应该**有多少货 |
| **盘点（conteo）** | 实际清点。可以是**抽查盘点**或**每周结算** |
| **每周结算（liquidación）** | 每周二的全面盘点，结出本周的**公斤数平衡** |
| **班次** | 从开班到交班的这段时间 |
| **支付方式** | Efectivo（现金）、Mercado Pago（电子支付）、Fiado（赊账）…… |
| **赊账 / 往来账** | 卖给熟客，之后再付 |
| **汇款（remesa）** | 分店付给加工厂的钱 |
| **同步** | 分店电脑和总部之间每分钟自动交换数据 |

> 商品、类别、客户和支付方式的**名称不翻译**，按录入时的西班牙语显示。本手册第一次出现时在括号里给出中文意思。
