# 核心概念

> **适合谁：** 所有人。  **时间：** 10 分钟。

六个想法几乎能解释系统做的所有事。每一条都链接到用到它的教程。

## 1. 订单和销售：称重的人不收钱

- 屠宰工录入**订单**：称好重的部位和价格。订单状态是**未结**。
- 收银员**收款**：订单变成**销售**，状态变为**已收款**。
- 顾客不付钱，就**作废**订单（会记录是谁、为什么）。
- 一张订单**只能收一次款**：两个收银台同时点它，第二个会收到提示。
- **收款时才扣库存**，录入订单时不扣。

→ [03 录入订单](../01-manual-usuario/03-armar-una-comanda.md) · [04 作废](../01-manual-usuario/04-mis-comandas-y-anular.md) · [06 收款](../01-manual-usuario/06-cobrar-una-comanda.md)

## 2. 从半边胴体到各个部位：分割

- 加工厂送来**半边胴体**。收货时**称重**（拍下秤的显示屏）并**挂进**冷库。
- **分割**时，**分割模板**把重量分配到各个部位：

  `部位公斤数 = 半边胴体重量 × (1 − 损耗%) × 该部位的%`

  例：120 公斤的半边胴体，损耗 2%，Asado de tira（肋排）占 15% → 120 × 0.98 × 0.15 = **17.64 公斤**肋排。
- 如果称了某些部位，就用实称的公斤数；其他部位用模板的数字。
- **分割损耗**＝半边胴体的重量减去所有部位之和。

→ [11 收货](../01-manual-usuario/11-recibir-despacho-del-frigorifico.md) · [13 分割](../01-manual-usuario/13-camara-y-desposte.md) · [26 模板](../01-manual-usuario/26-catalogo-precios-y-plantillas.md)

## 3. 库存是"应该"有多少

每种商品的库存是它所有变动的合计：

| 增加 | 减少 |
|---|---|
| 收货（商品）· 分割（部位） | 卖出 · 丢弃（损耗） |

再加上每次盘点留下的**调整**。**实际**有多少，只有盘点才知道。库存出现**负数**说明有错误：分割没录入、部位用别的名字卖了、或者到货没录入。

→ [14 查看库存](../01-manual-usuario/14-ver-el-stock.md)

## 4. 每周结算和公斤数平衡

每周（周二，开门前、新肉到货前）盘点所有货。负责清点的人**看不到**应有数量。关闭时，系统算出**公斤数平衡**：

```
  上次结算时的库存
+ 收货（半边胴体和商品）
− 卖出
− 分割损耗
− 丢弃
± 盘点短少或多出
= 剩余
```

**总损耗** = 分割损耗 + 丢弃 + 短少，按本周总量的百分比计算。

| 总损耗 | 含义 |
|---|---|
| 4% 以内 | 正常 |
| 4% 到 6% | 注意（总部显示橙色） |
| 超过 6% | 有问题（红色）：要找原因 |

关闭后，库存**等于实际盘点数**。不能撤销。

→ [15 盘点](../01-manual-usuario/15-liquidacion-semanal-contar.md) · [16 关闭](../01-manual-usuario/16-liquidacion-cerrar.md) · [17 抽查](../01-manual-usuario/17-conteo-de-control.md)

## 5. 收银台：进、出和点钞

- **班次**从期初现金开始（这笔钱来自 **Caja Central**（总钱箱））。
- 每笔销售计入它的支付方式；支出和取现从现金里减掉。
- **赊账**不是钱，是顾客的欠款。顾客付钱时，钱进收银台，并冲抵最早的欠款。
- 交班时，**实点现金 − 应有现金** = 差额，记入 **Diferencias de Caja**（收银差额）账户，并附上原因。
- 已交班的班次不能修改：错误用**账户调整**更正。

→ [05 开班](../01-manual-usuario/05-abrir-la-caja.md) · [08 赊账](../01-manual-usuario/08-fiado-y-cobro-de-deuda.md) · [10 交班](../01-manual-usuario/10-cerrar-la-caja.md) · [22 每周检查](../01-manual-usuario/22-controles-de-la-semana.md)

## 6. 分店和总部：每条数据只有一个主人

- **每家分店的电脑**都装有完整的系统，**断网也能卖货**。
- 有网络时，每分钟**上传**自己的数据，并**下载**总部的数据。

| 由总部录入 | 由各分店录入 |
|---|---|
| 商品、价格、照片、类别 | 销售、订单、收银班次 |
| 分割模板 | 收货、分割、库存 |
| 发货单 | 冷库、盘点和每周结算 |
| 各分店的往来账 | 员工和工位 |

- 数据**只能在录入的地方修改**。分店改了价格，这个修改会丢失；总部改了一笔销售，分店收不到。
- 每家分店用自己的**令牌**识别身份：总部只接受它自己的数据。
